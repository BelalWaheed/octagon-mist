Filter Octagon & Minimal Mist

A framework-agnostic design system with two themes that share one identity. Built with OKLCH color ramps, semantic tokens, and 8 multi-format build outputs.

Explore Components → Get Started
npm install @belalwaheed/octagon-mist
Or copy directly into your project: npx @belalwaheed/octagon-mist init
🎨

Two Themes, One Identity

Filter Octagon (warm, rich dark mode based on Monokai Pro) and Minimal Mist (clean, low-noise light mode) share the exact same 12-color hue ramps.

⚡

8 Output Formats

Exported out-of-the-box for plain CSS variables, Tailwind v4 (@theme), Tailwind v3, SCSS, Style Dictionary, Figma Variables, and JSON.

🏗️

3-Tier Token Architecture

Strict separation between Primitives, Semantics, and Components. Change one semantic mapping and every component updates instantly.

🚀

Zero Dependencies

Pure CSS custom properties with zero external JavaScript runtimes or build lock-ins. Works seamlessly with React, Vue, Svelte, or plain HTML.
