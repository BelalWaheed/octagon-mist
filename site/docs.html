Installation

Install the package into your project using npm or your favorite package manager.

npm install @belalwaheed/octagon-mist

npx CLI Setup

If you don't want to install an npm package and just want the CSS file in your folder:

# Copies tokens.css directly to ./src/styles/tokens.css
npx @belalwaheed/octagon-mist init

# Or specify a custom target directory:
npx @belalwaheed/octagon-mist init ./public/css

React / Vite / Next.js Setup

Import the CSS tokens entrypoint directly in your app root.

// In main.jsx, index.js, or _app.js
import '@belalwaheed/octagon-mist/css';

Tailwind v4 (@theme) Setup

Import the v4 theme file into your main CSS stylesheet.

/* In main.css or globals.css */
@import "@belalwaheed/octagon-mist/tailwind/v4";

Tailwind v3 (Config) Setup

Require the pre-built Tailwind v3 config preset in your `tailwind.config.js`.

// tailwind.config.js
const octagonMist = require('@belalwaheed/octagon-mist/tailwind/v3');

module.exports = {
  presets: [octagonMist],
  // ... rest of your config
};

SCSS / Sass Setup

Import SCSS variables into your stylesheet.

// In your main .scss file
@import "@belalwaheed/octagon-mist/scss";

Plain HTML Setup

Link directly to the CSS tokens file in your HTML header.

<link rel="stylesheet" href="node_modules/@belalwaheed/octagon-mist/css/tokens.css">

Theme Switching

Toggle between Filter Octagon (Dark) and Minimal Mist (Light) using the data-theme attribute on <html>.

<!-- Dark Theme (Filter Octagon) -->
<html data-theme="dark">

<!-- Light Theme (Minimal Mist) -->
<html data-theme="light">

<script>
  // Toggle at runtime with 1 line of JS:
  document.documentElement.dataset.theme = 'light'; // or 'dark'
</script>

3-Tier Architecture

Every token in the system is structured across 3 distinct layers:

  1. Primitives — Raw, theme-agnostic values (e.g. graphite-800, space-4, radius-md).
  2. Semantic Tokens — Primitives assigned a specific job (e.g. background.surface, text.primary). These change per theme.
  3. Component Tokens — Specific mappings assigned to component states (e.g. Button hover overlay).
